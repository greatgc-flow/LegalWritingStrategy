# 제16장. 한글 폰트·그림·차트·표·강조의 실제 선택 기준

기존 `docs/02_한글폰트_근거_추천_설치.md`의 상세 연구·설치 지침을 보존하고, 여기에는 소송전략 관점의 선택 게이트만 추가한다.

## 연구 해석

- 한글 서체별 **보편적인 승소·기소 효과**에 관한 직접 실험은 확인되지 않았다. 서체·화면/종이·표본·문장 난도·인쇄 품질의 상호작용을 고려한다.
- **맑은 고딕**은 Windows/Office 호환성 기본값(Windows에 이미 있는 경우 별도 다운로드 불필요); 별도 폰트파일 재배포 금지.
- **Adobe Source Han Sans(본고딕)**, **Source Han Serif(본명조)**: 공식 GitHub 릴리스에서 언어별 OTF/TTF 구성을 확인하여 설치. https://github.com/adobe-fonts/source-han-sans/releases ; https://github.com/adobe-fonts/source-han-serif/releases
- **Pretendard**: 공식 릴리스에서 고정형 OTF/TTF 다운로드; SIL OFL. https://github.com/orioncactus/pretendard/releases
- **Noto Sans/Serif KR**: Google Fonts 공식 페이지에서 다운로드 또는 제작환경의 패키지. https://fonts.google.com/noto/specimen/Noto+Sans+KR ; https://fonts.google.com/noto/specimen/Noto+Serif+KR

## 설치방법 (Windows 10/11)

1. 폰트의 **공식 릴리스**에서 사용자 PC에 맞는 TTF/OTF를 받는다. ZIP에는 저작권·용량 때문에 **폰트 파일을 포함하지 않는다**.
2. 압축을 푼 다음 확장자 `.ttf`/`.otf` 우클릭→`설치`(사용자) 또는 `모든 사용자용 설치`(관리자 권한). Windows `설정 > 개인 설정 > 글꼴`에서도 설치 가능.
3. Word/한글/LibreOffice 다시 실행 후 실제 패밀리 이름 확인; 변수폰트 문제 시 고정체 선택.
4. 샘플 `1/I/l`, `0/O`, `₩`, 숫자·한자·괄호를 포함해 PDF 렌더. `pdffonts`로 글꼴 포함 확인. 다른 PC와 흑백 인쇄에서 표가 깨지는지 확인.
5. 외부기관 공식 서식에서 요구한 폰트가 있으면 그 기준이 우선.

## 비주얼 사용 판단표

| 시각 요소 | 목적이 분명할 때 | 위험 및 QA |
|---|---|---|
| 굵게 | 핵심 사실·요건 소결·수치 | 단어 몇 개만; 전체 문장 남용 금지 |
| 밑줄 | 문서 표기상 구별해야 할 짧은 문구 | 지나치면 읽기 어려움; 링크와 혼동 주의 |
| 색상 | 내부용 확정/미확정 상태 | 흑백 출력 시 의미 보존, 제출용 절제 |
| 사건 연표 | 주장 시간순과 충돌 발견 | 출처 없는 날짜·상대관계 금지 |
| 자금흐름 | 계좌간 입출금 구분 | 송금 확인선과 추정 지시선을 다른 선/범례로 구별 |
| 표 | 증거·구성요건 대조 | 한 셀 장문 방지, 같은 열은 같은 의미, 표 아래 출처 |
| 차트 | 객관적 숫자 비교 | 데이터·기준일·단위 명시; 축 절단으로 오해 유발 금지 |

## 시각적 완결도 QA

- 본문 12pt 이상 등 **민사법정기준**은 해당 사건/서류에 직접 적용되는지 먼저 확인.
- 표/그림의 모든 선, 막대, 숫자, 동그라미에 `EV/FACT` 원천을 매핑. 원자료에 없는 인과·공모·지시를 화살표로 그리지 않는다.
- 표 내부 글자가 본문 기준 미달로 축소되는 것이 불가피하다면 원칙적으로 별도 자료로 분리하고 기관 서식 규칙 확인.
- 페이지/표 머리글/헤더·푸터/쪽번호/이미지 대체텍스트/PDF 검색 및 복사/실제 폰트 임베딩 검수.
- 실제 렌더가 성공해도 그 문서의 사실·법리 검증을 완료한 것은 아니다.
