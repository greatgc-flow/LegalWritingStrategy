## 검증 범위의 정확한 의미

- 자동검사 7/7은 **합성 레코드용 코드 단위 테스트**이며, 실제 법령 진위·증거 진정성 판정이 아니다.
- DOCX/PDF 검사는 **가상 서식**만 대상이며 사용자 PC와 한컴오피스 설치 검증을 의미하지 않는다.
- 서지목록 42편은 연구 **후보 색인**이다. 대부분 초록·메타데이터 수준이고 전편의 원문·방법론 검증이나 PRISMA 전수조사로 주장하지 않는다.
- 프레이밍·시각효과는 한국 형사사건 결과에 대한 직접적인 인과 입증 근거가 아니다.
- 내부 규칙 100점은 설계자가 정의한 체크리스트의 구조적 범위를 나타내는 자체점수다. 실제 완결성·기소/유죄·승소 가능성 100점이 아니다.
