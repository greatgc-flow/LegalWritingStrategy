# 제12장. 경찰·검사·법관의 판단 흐름에 맞춘 문서·자료 구성

## 핵심

**인용하기 쉬운 문장**은 강한 감정표현이 아니라 ①증거로 확인되는 사실 ②법적 관련성 ③확실성 범위 ④검증 가능한 출처로 이루어진다. '판결문에 복사하기 좋은 문장 수'를 KPI로 삼을 수는 있으나 유죄 확률을 의미하지 않는다.

## 독자별 필요 정보

| 독자 | 판단 또는 작업 | 우선 보여줄 요소 | 주의 |
|---|---|---|---|
| 수사관 | 사건의 사실·행위·관계자·미수사 자료 | 시간·인물·자금·문서 경로, 확인 대상, 수사 요청 | 미확인 고의·공모 확정 금지 |
| 검사 | 범죄혐의·수사기록·공소유지 위험 | 구성요건별 증거/공백, 증거능력·반론, 법령 적용 | 기소 결정 확정 요구 금지 |
| 형사법관 | 공소사실별 증거/법률 판단 | 유·불리 증거, 각 요건, 합리적 의심 여부 | 사실 인정은 재판부의 판단 |
| 민사법관 | 청구취지/요건사실/입증책임 | 다툼없는 사실, 쟁점, 청구원인·항변, 수치 산식 | 입증책임과 증명 정도 혼동 금지 |

## 추천 제출문서 구조

1. 표지: 사건식별·문서명·제출자·작성일(최신 서식 준수).
2. 1쪽 요지: '검토해 달라는 쟁점'과 근거의 방향, 요청하는 판단/수사. 공식 양식 또는 짧은 문서에서는 생략·축약.
3. 목차: 두세 단계 이하, 정보 제공형 소제목. 장문의 경우에만 수록.
4. 핵심 쟁점마다 동일 프레임: `쟁점 → 기준 법령/요건 → 확인 사실 → 증거·위치 → 가장 강한 반대사정 → 분석 → 소결`.
5. 사건 흐름: 일자순 표, 자금흐름, 조직도/명령흐름은 **법적 쟁점에 기여할 때만**. 화살표의 의미를 범례로 정의(`송금`, `진술`, `추정`, `지시 확인`).
6. 요청사항: 수사 대상, 자료 확보 범위, 판결·결정의 구체 범위.
7. 증거목록: `본문 ID ↔ 증거 ID ↔ 원본명 ↔ 페이지/타임코드 ↔ 원본 확인 상태`.
8. 별첨 원본: 증명자료의 전체 내용 및 필요한 검증 기록.

## 참고자료 위치의 세 겹 구조

- **본문:** 사실명제 바로 옆의 `증거번호·쪽·타임코드`를 우선. 짧은 인용이 판단에 결정적일 때만 전사 원문을 삽입.
- **본문 가까운 표/도표:** 두 문서 대조·시계열·증거 일관성처럼 실제 탐색 비용을 줄이는 경우에 한정.
- **말미:** 증거목록/원본/장문 녹취/복잡 계산표. **본문에 출처 없이 별첨만 모아 두면 추적 불능**.

분량은 법원의 구체 서식과 규정에 따르며, 민사 준비서면(민사소송규칙 제69조의4)의 30쪽 원칙을 모든 소송서류에 일반화하지 않는다. 링크는 원문을 실제로 식별해야 하고, 오프라인 제출 시 파일경로만 던지지 말고 증거번호와 페이지를 표기한다.

## 문체 시험

- `행위자가 무엇을 했는지 알 수 있는가?` 
- `사실과 평가가 같은 문장에 합쳐져 있지 않은가?`
- `능동형으로 바꾸면서 행위자 불확실성을 지워버리지 않았는가?`
- `~하지 않았다`가 법률적 중요 사실이라면 그대로 유지했는가?
- `법률전문어를 삭제하면 법적 의미가 흐려지는가?`
- `두괄식에 필요한 설명이 빠져 오독될 위험은 없는가?`
- `볼드·밑줄·색 없이 흑백으로 읽어도 이해되는가?`
- `AI 작업 메타문구(수정본, 프롬프트, 내가 볼 때 등)는 본문에서 제거되었는가?`

## 인용가능성 점검 예시

**나쁨:** `피고소인 측은 일관되게 범행을 은폐했습니다.` (행위/증거/시기 없음)

**개선:** `2025년 2월 3일 A는 B에게 ‘계약금이 입금되었다’는 메시지를 보냈다(증 4, p.2). 같은 날 B 계좌의 입금 여부는 확인 자료가 없어 확정할 수 없다. 해당 발언의 정확성과 실제 입금 여부의 대조가 필요하다.` (가상 예시)

**분리형:** `사실 → 법적 쟁점에서 왜 의미 있는지 → 불리한 사정·한계 → 요청`을 독립 문장으로 작성. 수사기관/법관이 자기 판단 문장으로 바꾸기 쉽게 한다.

## 실무 지표

- 핵심 쟁점별 **입증 가능한 사실명제** 개수
- 사실명제에서 원본까지의 역추적 성공률
- 의도적 반론 누락 0건 여부
- 인용문·수치 오류 건수
- 1쪽 요지의 법적 판단과 본문 간 충돌 건수
- 도표의 관계선·금액·시기 출처 누락 건수

지표를 높이기 위해 중복문장을 늘리거나 내용을 과장하는 행동은 금지한다.
