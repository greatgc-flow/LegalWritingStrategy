### 적용일 확인카드

`LAW_ID / 법령명 / 조문 / 원문 URL / 법률번호 / 시행일 / 개정일 / 행위일 / 통지일 / 제출일 / 부칙 적용례 / 적용 근거 / 확인자 / 최종확인일`.

형사 이의신청 예시: **2026-10-02 개정 시행 전 통지·처분 사건**의 기한을 현행 조문만 보고 단정하지 않는다. 2026-08-04 관련 개정법률과 2026-09-29 일부개정 및 경과규정을 모두 확인한다. 헌재 결정·법원 판례·대통령령도 해당 쟁점에 따라 추가 검토한다.

### 출처·법령 오독 방지

- 민사소송규칙 제4조가 글꼴 **이름**을 지정한다고 쓰지 않는다. 이름은 호환성·가독성에 따른 권고.
- '형사 서면의 글꼴은 12pt 의무'라고 일반화하지 않는다.
- 각주·본문 인용 방식에 관한 연구 권고와 제출기관이 요구하는 필수 서식을 혼동하지 않는다.
- 판결문을 인용할 때는 사건번호·법원·선고일·판시 대상·법률상 적용 시점을 원문으로 확인한다. 동일 문구가 반대 결론을 지지하는 맥락에서 나온 부분만 잘라 인용하지 않는다.
- 해외 자료는 한국 법령 또는 대법원 판례로 표기하지 않는다.
- PDF에서 본문이 12pt라고 하더라도 실제 워드의 모든 run/표 셀 스타일이 12pt인 것은 아니다. 템플릿 기본 스타일 검사+PDF 시각 검수 병행.

### 제출 전 확인 (CASE-SPECIFIC)

1. 제출자격·관할·기한·처분 통지일과 입증서류.
2. 관련 기관의 **현재 공식서식**과 전자제출 가능 파일 형식·용량·서명 요건.
3. 개인정보, 주민등록번호·계좌·제3자 정보의 제출 필요성/마스킹 정책.
4. 녹취·문자·사진의 원본성 및 실제로 제출할 형태와 진술서의 차이.
5. 불리한 자료의 존재와 제출 의무/적절성; 법률가와 검토할 쟁점.
