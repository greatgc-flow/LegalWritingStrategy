# 한글 법률문서 서체·판면·설치 가이드

기준일 2026-11-06. 이 문서는 **규정상 의무 / 연구결과 / 실무 권고**를 분리한다. 본문 글꼴에 '최고의 유일한 폰트'가 존재한다는 실증은 확인되지 않는다.

## 1. 직접 확인된 한국 법원 기준

- [민사소송규칙 제4조](https://www.law.go.kr/LSW/lsInfoP.do?lsId=005770): 간결·분명한 작성. 특별한 사정이 없는 한 A4 세로(210×297mm), **위 45mm, 아래 30mm(쪽수 표시 제외), 좌우 각 20mm**, **글자 12pt 이상**, **줄간격 200% 또는 1.5줄 이상**. 이는 민사 소송서류 규정이며 경찰·검찰에 일반적으로 직접 적용된다고 단정할 수 없다.
- [민사소송규칙 제69조의4](https://www.law.go.kr/LSW/lsInfoP.do?lsId=005770): *준비서면* 원칙적으로 30쪽 상한, 합의 예외 및 감축명령 가능, 불필요한 중복 기재 금지. 모든 법률문서의 공통 30쪽 상한이 아니다.
- [민사소송 등에서의 전자문서 이용 등에 관한 규칙](https://law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lspttninfSeq=111696): 2026-11-03 시행본까지 확인했으며, 전자제출 허용 형식·용량·서명·첨부 조건은 실제 사건의 최신 포털 안내를 우선한다.
- 형사 고소장·진술서·의견서의 표지는 해당 기관의 공식서식을 우선한다. '민사 규정'을 형사 의무로 잘못 표시하지 않는다.

## 2. 한글 폰트 연구 — 과잉 일반화 금지

1. 옥준영·이석재·정인욱(2024), 「아이트래킹 데이터를 활용한 한글 세리프체와 산세리프체의 가독성 비교 분석」, **58명**, DOI [10.5626/KTCP.2024.30.6.264](https://www.kci.go.kr/kciportal/ci/sereArticleSearch/ciSereArtiView.kci?sereArticleSearchBean.artiId=ART003087922). 연구조건에서 궁서의 일부 지표가 유리했으나, 이를 근거로 모든 법률서류 본문을 궁서로 설정하지 않는다. 실험 글꼴·지표·참여자·서면종류의 전이 한계가 있다.
2. 2026년 화면/종이 × 세리프/산세리프 2×2 실험(N=132)은 실험된 Verdana와 Times New Roman 사이에 결정적 보편 우위를 확인하지 않았다. DOI [10.1080/0144929X.2026.2678378](https://doi.org/10.1080/0144929X.2026.2678378). **영어·일반 텍스트** 실험이라는 한계를 분명히 한다.
3. 2026년 법률문서 강조 실험(비법률 전공자)은 볼드·밑줄보다 **문장 구조의 난이도**가 독해에 더 큰 영향을 미칠 수 있음을 보였다. DOI [10.18848/2325-1581/CGP/A174](https://doi.org/10.18848/2325-1581/CGP/A174).

판단: 정확한 글자, 12pt 이상, 안정적인 글자 간격, 적절한 줄 길이·여백, 명료한 소제목, 좋은 PDF 대체/포함 처리가 특정 폰트의 분위기보다 중요하다.

## 3. 추천 후보별 비교 (검증된 품질보다 실무 특성)

| 후보 | 특성 및 권장 역할 | 다운로드·권리 | 유의사항 |
|---|---|---|---|
| **맑은 고딕** | Windows/Office 호환성이 좋은 **기본 우선안**; 긴 본문·표에 적합 | Windows/Office 설치 환경에서 제공되는 상용 서체. 별도 재배포 금지 | 다른 OS에 없을 수 있으므로 PDF 포함상태 확인 |
| **본고딕 Source Han Sans / Noto Sans CJK KR** | 개방형 환경의 산세리프 대안; 한글·한자와 문서간 일관성 | [Adobe 공식 저장소](https://github.com/adobe-fonts/source-han-sans), [Google Noto](https://fonts.google.com/noto/specimen/Noto+Sans+KR) | 실제 설치된 폰트 패밀리명 확인, 배포판별 글리프 차이 |
| **본명조 Source Han Serif / Noto Serif CJK KR** | 장문의 차분한 본문, 별첨의 문헌성 강화 대안 | [Adobe 공식 저장소](https://github.com/adobe-fonts/source-han-serif), [Google Noto](https://fonts.google.com/noto/specimen/Noto+Serif+KR) | 세리프가 항상 더 잘 읽힌다는 근거는 없음 |
| **Pretendard / Pretendard GOV** | 수치 중심 표·중간제목과 디지털 리뷰에 적합 | [공식 GitHub 릴리스](https://github.com/orioncactus/pretendard/releases/latest), SIL OFL | 문서 편집기에 따라 가변 폰트가 깨질 수 있어 고정 TTF/OTF 우선 |
| **KoPub World 바탕·돋움** | 한자 많은 서류나 출판풍 검토본의 보조 후보 | [한국출판인회의 안내](https://www.heritagelab-chacl.org/9e8dfdd2-0faf-4224-a88e-6bd841c3ce06) | 무료여도 등록·라이선스 제약 있음. 무단 수정·서체 재배포 금지 |
| **나눔명조·나눔고딕** | 설치가 쉽고 무난한 대안 | [네이버 나눔서체 공식 안내](https://hangeul.naver.com/font) | 문서 출력환경에서 이름·굵기 일치 확인 |

**권장 프로필 3종**
- 호환성 최우선: 맑은 고딕 12pt, 제목 14/16pt. DOCX는 일반 Office 환경, 최종본은 임베딩된 PDF로 제출.
- 공개·이식성 최우선: 본고딕(Noto Sans CJK KR) 12pt, 제목 동일 계열 14/16pt.
- 긴 서술 중심: 본명조 12pt + 본고딕 제목(서체 2종 이하). 단, 실제 판면의 시각검토 후 선택.

**권장하지 않는 것:** 작은 글자(11pt 이하로 억지 축약), 너무 가는 폰트, 여러 폰트 혼용, 강조만으로 문장의 불명료함 은폐, 회색의 저대비 본문, 이미지로 변환된 전면 텍스트, 출처 없이 별첨을 본문에 마구 붙이기.

## 4. Windows 설치 절차 — 글꼴 파일은 패키지에 포함하지 않음

1. 위 공식 배포처에서 **TTF/OTF 데스크톱용** 파일을 내려받는다. 다운로드한 zip을 압축 해제한다.
2. `.ttf` 또는 `.otf`를 선택해 오른쪽 클릭 → **설치(현재 사용자)** 또는 **모든 사용자용 설치**(관리자 권한 필요). Windows 11에서는 `설정 → 개인 설정 → 글꼴`로 드래그할 수 있다.
3. Word/한글/LibreOffice를 재시작하고 새 문서의 글꼴 목록에 이름이 나타나는지 확인한다.
4. 100% 확대에서 한글, 한자, 괄호, `1/0/I/l`, ₩, 마이너스와 표 숫자를 눈으로 확인한다.
5. PDF로 내보낸 뒤 `pdffonts 파일.pdf`가 있다면 글꼴 포함 여부를 확인한다. PDF 텍스트를 검색·복사할 수 있는지와 다른 PC에서의 표시를 점검한다.
6. 문서 파일(.docx)을 공유할 때 수신자에게 동일 글꼴이 없으면 줄바꿈·쪽번호가 변할 수 있다. 제출용 PDF를 함께 관리한다.

**PowerShell 폰트 목록 확인(읽기 전용):**
```powershell
Get-ChildItem "$env:WINDIR\Fonts" -Filter *.ttf | Select-Object -First 20 Name
Get-ItemProperty 'HKLM:\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Fonts' | Format-List
```
설치 스크립트에서 서체 파일 다운로드는 자동으로 수행하지 않는다(라이선스·버전·내부망 정책 확인).

## 5. 폰트 실증 A/B 시험법

실제 사건과 무관한 1,000자 분량 시험 텍스트에 대해 **내용·용지·글자 크기·줄간격·문단폭을 고정**하고 서체만 바꾼다. 화면/인쇄에서 찾기 속도, 오독, 표 수치 판독, 피로도, 글꼴 대체 여부, PDF 검색 가능성, 장문 가독성을 비교한다. 추천점수는 서체의 우월성 증명이 아니라 **해당 조직·장비·독자를 위한 선택 결과**로 기록한다.
