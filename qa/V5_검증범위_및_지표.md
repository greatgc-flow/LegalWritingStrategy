# V5 검증 계획·중단 규칙

## 검증범위

- 이전 V4.1에서 작업 규칙을 승계하여 V5 문서·전략 프롬프트·참고 연구·도구설정을 보완했다. 구 문서 파일은 삭제했으며, 과거 점수·기준일·변경 이력은 git 기록에서 확인한다. 현재 SSOT는 `docs/00_최종_통합마스터_V5.md`다.
- 자동 테스트는 **내부 파일구조·가상 사례에서의 참조/인용 불일치 탐지**를 검증한다. 실제 법원 승소율·증거 진정성·법률자문 정확도를 검증하지 않는다.
- 새 DOCX는 실제 PDF 렌더/페이지 이미지 확인 필요. PDF 자동검사·a11y는 보조 수단이며 레이아웃 시각검사를 대체하지 않는다.

## 정적 점검

1. 전략 S0~S6 실제 파일 7개 존재, 단계 이름/목적 일치.
2. P0~P8 9개 기존 프롬프트 존재.
3. 연구 register의 DOI/출처/검증 상태 존재, 임의 숫자 100점 금지.
4. SHA-256, ZIP CRC, 중복 경로, 상대경로 존재성 검사.
5. Windows 설치 스크립트 기본 미리보기 및 비대화식 자동 설치 금지.
6. 이전 버전과의 변경 차이는 git 이력으로 확인·기록한다.

## 동적 점검

- 모든 근거ID 유효한 가상자료 정상 통과.
- 누락 증거, 누락 불리자료, 불리자료 대응 빈칸, 상충 금액, 변형 인용문, 미확인 법령을 개별 실패로 탐지.
- 실제 민·형사 사건의 사실관계와 법리는 독립 변호사·원본자료 대조 없이 평가 불가.

## 최종 세 가지 상태

`READY_FOR_HUMAN_REVIEW`(확인된 범위를 표시하여 사람의 검토에 회부), `NEEDS_VERIFICATION`(사건 적용 전 자료·법리·출력·승인 추가 확인), `SUBMISSION_BLOCKED`(법리·증거·절차의 중대한 공백). 내부 검사 통과만으로 사건 상태가 자동 승격되지 않으며, 사건별 법률가 검토가 필요하다.
