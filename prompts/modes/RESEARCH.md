# RESEARCH — 법률조사

공통 규칙: [공통 지침](../00_공통규칙.md). 실행 계약: [모드 카탈로그](../../config/mode_catalog.json). 사용법: [실행 안내](../../docs/workflow_modes.md).

서면이 없어도 법률 질문·관할·관련 시점으로 시작한다. 기본 결과는 법률검토 메모이며 자동 제출문 작성이나 기관 전송은 하지 않는다.

## 입력과 범위
질문, 관할/절차, 사건에 관련된 날짜, 조사 범위를 정한다. 개인정보가 포함된 검색어와 외부 서비스 입력의 허용 범위를 확인한다. 계정·인증값은 저장하지 않는다.

## 실행
공식 법령·판결 원문을 우선 확인하고 검색어·대상·확인일·확보 범위를 남긴다. 판례 실재, 인용 내용, 사실관계/법률/시점의 적용 가능성을 각각 검토한다. 관련 반례·다른 해석과 부칙을 확인한다. 보조 저장소의 해시 일치를 공식 원문 재확인으로 승격하지 않는다. 접근 실패와 관련 판례 부존재를 혼동하지 않는다.

## 인계
질문별 결론과 한계, 법률 근거·정확한 인용 위치, 검색 기록, 확인하지 못한 출처를 반환한다. 요지·발췌·전문·서지의 확보 수준을 구분한다. 학술 연구의 결론과 법적 권위를 별도로 취급한다.

## 완료 조건
핵심 결론의 근거와 적용 시점이 추적되고 반대 논거가 검토됐다. 조사가 불완전하면 범위와 추가 확인을 명시한다. API 인증·본문 확보·후속 판례 검색을 실제 수행하지 않았으면 성공으로 기록하지 않는다.

미실시 항목은 `NOT_TESTED`로 기록한다. 최종 판정은 공통 기준의 세 값만 사용하며 이 안내나 실행계획만으로 제출 적합성을 판단하지 않는다.
