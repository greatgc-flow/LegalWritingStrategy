# COMPARE — 문서·버전 비교

공통 규칙: [공통 지침](../00_공통규칙.md). 실행 계약: [모드 카탈로그](../../config/mode_catalog.json). 사용법: [실행 안내](../../docs/workflow_modes.md).

둘 이상의 문서·증거·버전을 대조한다. 차이 분석은 정본 선택·문서 통합·원문 수정의 승인과 다르다.

## 입력과 범위
비교할 최소 두 대상의 고정 버전·해시·출처 종류와 비교 목적을 확인한다. 원본/전사, 이전/개정, 서로 다른 진술/판결 등 비교 관계를 구분한다. 자료가 한쪽만 있으면 양방향 비교를 완료했다고 하지 않는다.

## 실행
문단·표·각주·날짜·주체·금액·원문 위치를 정렬한다. 표현 차이, 문단 이동, 수치 차이, 사실 충돌, 법적 의미 변화, 판독 불확실성을 구별한다. 서로 다른 시점·주체를 말하는 자료를 같은 사실의 모순으로 단정하지 않는다. 추출 과정의 누락과 원문 자체의 차이를 분리한다.

## 인계
각 차이의 양쪽 위치·원문·분류·관련 주장·의미 영향·검토 필요를 반환한다. 일치 판단의 범위도 남긴다. 문단/행 좌표와 실제 인쇄 쪽수를 구별하고 후보 정본 채택·통합은 별도 작업으로 남긴다.

## 완료 조건
중요 차이에 양쪽 근거가 있고 누락된 표·이미지·각주를 명시한다. 비교 도구의 문자 차이가 의미상 모순을 자동 증명하지 않는다. 원본을 변경하지 않으며 출력 파일은 비교 보고로 한정한다.

미실시 항목은 `NOT_TESTED`로 기록한다. 최종 판정은 공통 기준의 세 값만 사용하며 이 안내나 실행계획만으로 제출 적합성을 판단하지 않는다.
