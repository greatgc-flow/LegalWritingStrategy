# AUDIT — 독립감사

공통 규칙: [공통 지침](../00_공통규칙.md). 실행 계약: [모드 카탈로그](../../config/mode_catalog.json). 사용법: [실행 안내](../../docs/workflow_modes.md).

제출 후보를 원본·공식 근거·실제 출력과 대조하는 읽기 중심의 감사다. 기본 권한은 후보 파일 수정이 아니라 새 검토보고 작성이다.

## 입력과 범위
후보 버전/해시, 원증거와 위치, 법률 근거 장부, 실제 출력 검수 자료를 확인한다. 빠진 자료는 감사 범위의 제한으로 명시하며 있는 자료부터 검토한다.

## 실행
P8과 S6의 종방향·횡방향 검사를 수행하고 필요한 세부 단계로 돌아가 확인한다. 다른 검토자의 결론을 정답으로 제공받지 않은 1차 결과를 먼저 남긴다. 이후 결과를 비교하고 불일치는 원문으로 해결하거나 미해결로 기록한다. 기술적 검사 통과, 실제 원본 대조, 법률 적용 판단, 사람 승인은 별개다.

## 인계
발견사항·심각성·원문 위치·영향 문단·수정 제안·재검사 방법, 실제 검사한 범위, 미실시 항목, 검토자와 버전, 불일치 처리 내역을 반환한다. 본문을 고치려면 별도 수정 범위 승인을 받아 수정 모드로 전환한다.

## 완료 조건
확인된 오류와 확인하지 못한 항목을 구별하고 중대한 미해결 문제를 숨기지 않는다. 검사기의 높은 점수로 원본·법리·출력 검수 공백을 상쇄하지 않는다. 최종 제출 승인은 사람이 한다.

미실시 항목은 `NOT_TESTED`로 기록한다. 최종 판정은 공통 기준의 세 값만 사용하며 이 안내나 실행계획만으로 제출 적합성을 판단하지 않는다.
