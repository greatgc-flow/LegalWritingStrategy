# P4 — 목차·정보 구조 설계

사용 전 `prompts/00_공통규칙.md`를 참조한다. **현재 단계에서 허용하지 않은 변경은 하지 말 것.**

## 작업 지시
상위 목적→쟁점→요건→사실/증거→문단의 수직 경로를 매핑한다. 중복 책임을 제거하고 하나의 증거가 여러 쟁점을 지지하는 다대다는 보존한다. 변경 전/후 목차와 문단 이동 표를 작성하며 본문은 아직 변경하지 않는다.

## 필수 입력
- 문서/사건과 버전 ID 및 승인된 작업 범위
- 해당 단계에 필요한 FACT/EV/LAW/ISS/PAR 연결과 원본 출처
- 검증 불가능 항목 목록(없다면 '확인된 자료에 한함')

## 제출 형식(메타 보고서에만)
- 변경 제안 목차, 문단 이동표, 누락/중복/영향평가
- `PASS / FAIL / NOT_TESTED`, 다음 단계의 필요 입력
- 필요 시 문장별 기존·개정·근거·영향·승인상태

## 자동 중단
원본/법률/증거의 변형 가능성이 발견되면 최종 문안이라고 표시하지 않고 책임 단계로 되돌린다.
