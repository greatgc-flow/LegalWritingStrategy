# P8 — 독립 검수·최종판정

사용 전 `prompts/00_공통규칙.md`를 참조한다. **현재 단계에서 허용하지 않은 변경은 하지 말 것.**

## 작업 지시
이전 수정자와 다른 관점에서 V1~V5/H1~H8/G1~G7을 검사한다. G1~G7은 `docs/00_최종_통합마스터_V5.md` §13.2의 단일 표를 따른다. 중대한 법적 오류·증거 왜곡·기한/절차 문제는 점수와 무관하게 SUBMISSION_BLOCKED. 독해·인용성은 실무자 평가 없으면 항목별 NOT_TESTED로 기록한다. 승인되지 않은 결론 변동 시 반려 후 이전 단계로 롤백.

## 필수 입력
- 문서/사건과 버전 ID 및 승인된 작업 범위
- 해당 단계에 필요한 FACT/EV/LAW/ISS/PAR 연결과 원본 출처
- 검증 불가능 항목 목록(없다면 '확인된 자료에 한함')

## 제출 형식(메타 보고서에만)
- 오류·재수정/불확실성표와 항목별 검사 결과, 제출 승인은 사람에게
- 최종 판정: `READY_FOR_HUMAN_REVIEW / NEEDS_VERIFICATION / SUBMISSION_BLOCKED` 중 하나, 다음 단계의 필요 입력. 사건별 법률가 검토가 필요하다.
- 필요 시 문장별 기존·개정·근거·영향·승인상태

## 자동 중단
원본/법률/증거의 변형 가능성이 발견되면 최종 문안이라고 표시하지 않고 책임 단계로 되돌린다.
